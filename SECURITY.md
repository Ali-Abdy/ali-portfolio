# Security

If you find a security issue in this portfolio, contact **aliabdihaj@gmail.com** with the affected URL or file, a short description, and safe reproduction steps. Please avoid public issues containing credentials, private information, or exploit details before the issue has been assessed.

Test only with your own data. Do not run traffic floods, access other people's accounts, or test third-party services linked from the portfolio.

The current review, controls, known limitations, and pre-deployment checks are documented in [docs/security-review.md](docs/security-review.md). That review is a point-in-time assessment, not a security guarantee.
