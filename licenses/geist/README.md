# Geist font license

`OFL.txt` is the unmodified SIL Open Font License and copyright notice published for Geist by the Google Fonts repository:

https://github.com/google/fonts/blob/main/ofl/geist/OFL.txt

Retrieved on 20 September 2026. The application uses Geist through `next/font/google`; the build downloads and self-hosts the font files. Visitor browsers do not need to contact Google Fonts. The full license is included in the generated public third-party notices. Recheck the font source/license when changing font families or distribution.
